{% trans 'Правила' %}

{% trans 'Требования к участникам конкурса' %}

  • {% trans 'конкурсные виды должны быть посеяны в отдельные горшки (квадратной/круглой/многоугольной формы)' %};
  • {% trans 'наличие фотоаппарата — примерно раз в месяц необходимо делать фото конкурсных сеянцев' %};
  • {% trans 'наличие линейки с миллиметровой шкалой' %};
  • {% trans 'наличие информации об источнике семян и их точном количестве в посеве' %}.

{% trans 'Требования к конкурсным фото' %}

  • {% trans 'Ракурс: вертикально сверху или под небольшим углом' %};
  • {% trans 'Освещение: лучше искусственное, т.к. оно не меняется в зависимости от сезона' %};
  • {% trans 'Ракурс и освещение должны быть по возможности одинаковые на протяжении всего марафона' %};
  • {% trans 'Позиционирование: горшок на фото должен стоять всегда одной и той же стороной (можно сделать метку на одном из бортов)' %};
  • {% trans 'Вдоль нижнего борта должна быть видна шкала линейки (только на первом фото + после каждой смены горшка)' %};
  • {% trans 'Борта горшка должны попадать в кадр' %};
  • {% trans 'Фото не обязательно должно быть кадрировано — всё лишнее будет обрезано' %};
  • {% trans 'Отправлять фото в чат необходимо "как файл", а не "как фото"' %}.

{% trans 'Зачем нужна линейка?' %}

{% trans 'Линейка на фото необходима для понимания масштаба на фото в конкурсной таблице. При пикировке в другой (более крупный) горшок — из-за большей площади растения на фото после пикировки становятся мелкими' %}.

{% trans 'Линейка может быть любая: распечатанная на принтере, гостированная, школьная, главное чтобы на ней была шкала миллиметров. Для распечатанных на принтере линеек следует проверить, что миллиметры соответствуют своему размеру' %}.

{% trans 'Линейку нужно приложить к горшку вдоль нижнего борта, чтобы она попадала в кадр. Не имеет значения, куда прикладывать ноль, главное чтобы была видна шкала' %}.

{% trans 'Если не хочется каждый раз возиться с линейкой, то это можно сделать только на первом фото. На последующих фото ориентиром для выравнивания масштаба будет служить горшок (в этом случае горшок должен попадать в кадр на всех фото!). Ещё раз прикладывать линейку будет нужно в случае смены горшка (при пересадке растений), чтобы сохранить масштаб' %}.

{% trans 'Наличие масштаба и возможность понять размер сеянцев — повышает качество данных и научную ценность материалов, получаемых в результате проведения Марафона' %}.

{% trans 'Выбор победителей: Правила проведения голосований' %}

  • {% trans 'Чтобы стать номинантом нужно предоставить от 1 до 3 фото ваших сеянцев, соответствующих данной номинации' %}.
  • {% trans 'Для финальных фото разрешается использовать выигрышный ракурс, дополнительный свет, фон, т.е. проявить фантазию. Единственное требование: хотя бы одно фото из предоставленных должно быть общего плана, т.е. целиком вмещать растения и горшок' %}.
  • {% trans 'Для номинаций, в которых участвует более одного растения (N растений), количество фотографий может быть от 1 до N+1 (например для номинации Лучшая тройка можно предоставить от 1 до 4 фото)' %}.
  • {% trans 'Фото для номинации не обязательно делать в день голосования, их можно сделать заранее, начиная с 16 сентября' %}.
  • {% trans 'Каждый зарегистрированный участник может участвовать в нескольких номинациях' %}.
  • {% trans 'Голосование проходит в Telegram в открытом режиме' %}.
  • {% trans 'Оставить свой голос может любой участник чата, в том числе не являющийся участником марафона' %}.
  • {% trans 'Голосовать за себя не разрешается' %}.
  • {% trans 'На голосование в каждой номинации отводится 1–2 дня, но этот период может быть скорректирован в процессе' %}.
  • {% trans 'Голосование за следующую номинацию возможно только после окончания голосования за предыдущую' %}.
  • {% trans 'Публикация дополнительных фото конкурсанта в период проведения голосования не допускается.' %}

{% trans 'Общий порядок проведения голосования за номинацию' %}:

  1. {% trans 'Объявление номинации (в соответствии с графиком)' %};
  2. {% trans 'Сбор фото от номинантов' %};
  3. {% trans 'Проведение голосования' %};
  4. {% trans 'В случае ничьей запускается еще одно голосование' %}.
